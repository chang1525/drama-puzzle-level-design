# DRAMA PUZZLE — Level Design Submission

GitHub Pages package for the Level Design assignment.

## Deploy in about 2 minutes

1. Create a GitHub repository, recommended name: `drama-puzzle-level-design`
2. Upload **the contents of this folder** to the repository root (`index.html`, `tool/`, `levels/`, `assets/`, `.nojekyll`)
3. Commit to `main`
4. Open **Settings -> Pages**
5. Under **Build and deployment**, choose **Deploy from a branch**
6. Branch: `main`, folder: `/ (root)` -> Save
7. Wait for GitHub Pages to publish the site

The final URL normally looks like:
`https://<github-username>.github.io/drama-puzzle-level-design/`

## Test checklist after deployment

- Open `index.html`
- Click TEST L001 and TEST L008
- Confirm Tool loads the correct level and enters PLAY automatically
- Confirm READ REPORT opens the Google Docs report
- Confirm OPEN LEVEL SPINE opens the Google Sheet
- Test on a phone once

## Important after you get the final Pages URL

Add the Pages URL back into:
- the report's Quick Access / resource section
- Google Sheet `00_OVERVIEW`
- Google Sheet `03_LEVEL_INDEX_L1-10` as the TEST link for each level

This creates two-way navigation: Report / Sheet -> Hub -> Tool -> Level.
